# Mes Tâches

Application web de gestion de tâches (PWA), installable sur iPhone et utilisable hors ligne.
Les tâches sont enregistrées sur l'appareil (aucun compte, aucun serveur).

## Mise en ligne (GitHub Pages)

1. **Settings → Pages**
2. *Source* : **Deploy from a branch**, choisir la branche et le dossier `/ (root)`, puis **Save**
3. Le site est disponible à l'adresse : https://ryu-95-dev.github.io/t-ches-gestion-/

## Installation sur iPhone

1. Ouvrir le lien dans **Safari**
2. Bouton **Partager** → **Sur l'écran d'accueil**
3. L'icône « Tâches » apparaît comme une vraie app
